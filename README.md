# 📅 IEE IHU Exams Monitor Bot
Ένα Discord bot γραμμένο σε **Bun** + **discord.js** που παρακολουθεί τη σελίδα του [Προγράμματος Εξεταστικής (Τμήμα Μηχανικών Πληροφορικής και Ηλεκτρονικών Συστημάτων - ΔΙΠΑΕ)](https://www.iee.ihu.gr/exams-program/) και στέλνει αυτόματη ειδοποίηση όταν το πρόγραμμα δημοσιευτεί ή ανανεωθεί.

## 🔎 Πώς λειτουργεί
Το bot ελέγχει τα δεδομένα **iCalendar (iCal)** του τμήματος κάθε 5 λεπτά (το χρονικό διάστημα είναι configurable). Όταν το πρόγραμμα δεν έχει ανακοινωθεί ακόμα, η σελίδα δεν επιστρέφει κανένα μάθημα (`VEVENT`). Μόλις το πρόγραμμα εμφανιστεί, το bot στέλνει μια `@everyone` ειδοποίηση στο καθορισμένο κανάλι του Discord.

## 🛠️ Εγκατάσταση
1. **Δημιουργήστε ένα Discord bot** στο [discord.com/developers](https://discord.com/developers/applications)
2. **Εγκαταστήστε το Bun** από το [bun.sh](https://bun.sh)
3. **Κλωνοποιήστε το repository και εγκαταστήστε τα packages:**
   ```bash
   git clone <repo>
   cd ExamScheduleBot
   bun install
   ```
4. **Δημιουργήστε ένα αρχείο `.env`** και προσθέστε τα στοιχεία:
   ```env
   DISCORD_TOKEN=το_δικό_σας_discord_token
   CHANNEL_ID=το_id_του_καναλιού_σας
   CHECK_INTERVAL=5 (5 λεπτά default)
   ```
5. **Εκκίνηση του Bot:**
   ```bash
   bun run start
   ```

## ⚙️ Μεταβλητές Περιβάλλοντος (`.env`)
| Μεταβλητή        | Προεπιλογή | Περιγραφή |
|------------------|------------|-----------|
| `DISCORD_TOKEN`  | —          | Το Token του Discord Bot σας. |
| `CHANNEL_ID`     | —          | Το ID του καναλιού όπου θα στέλνονται οι ανακοινώσεις. |
| `CHECK_INTERVAL` | `5`        | Χρόνος (σε λεπτά) αναμονής μεταξύ των ελέγχων. |

## 👨‍💻 Ανάπτυξη (Development)

Για να τρέξετε το bot με δυνατότητα αυτόματης επανεκκίνησης όταν κάνετε αλλαγές στον κώδικα (watch mode):
```bash
bun run dev
```
